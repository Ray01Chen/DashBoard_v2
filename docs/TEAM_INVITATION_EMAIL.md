Please ask each department to review its settings, configure production targets and complete its hourly production records. Default daily targets are distributed across production intervals by production time. Interval targets can be adjusted for the selected production date without changing the Settings defaults.

Select Line and Model; all configured stations are listed automatically. Enter **Target and Actual for each station and time slot** in the compact table. Click **Add issue** or its one-line preview to edit notes with quick text and autosave. People and owners remain captured and are available in production details. Expand **Excel import & templates** when needed. Targets start from the daily preset and production minutes and can be adjusted without changing the preset or other stations. Managers configure job/station pairs and select an output station in the same Line configuration page. Dashboard totals use that source station to avoid counting products repeatedly across stations. Excel import includes a preview and supports different station values.

This is an **early release for trial use and feedback**. Production results currently need to be entered **manually**. A future version is planned to integrate automated production data collection. Please ensure each department completes its production records during this pilot stage.

In Line configuration, managers can uncheck **Produces output** for stations that do not need reporting. These stations stay visible with read-only history and are skipped by batch entry and Excel templates. **Fill interval** is highlighted at the top right; its window lets you choose another Line/Model, enter Target and Actual, and return to the selected unit when applying or closing. Each page now has a separate address for direct access, refresh and browser navigation. Product headings use two lines without the Model prefix; stored names are unchanged.

Managers can drag stations into the desired order in **Line configuration** and **Save settings**. Production entry, station details and exports follow that order. For common values, use **Fill interval** beside the Line/Model heading to set Target and Actual together for all enabled stations in one time slot. Entered columns overwrite earlier individual values; blank keeps a column unchanged. Stations remain individually editable afterward. Issues and default daily targets are preserved.

Detailed setup and reporting instructions, including screenshots, are available under **User guide**, tailored to the logged-in account. The interface supports English, Chinese and Thai. Managers should use **Save settings** to publish shared settings; **Save draft** stays in the current browser.

Historical sample reports dated **November 3, 2026** remain available for reference. Please review the current line/model station configuration and personnel before operational use; existing department settings are retained.
