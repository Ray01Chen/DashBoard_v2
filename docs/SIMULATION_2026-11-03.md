## 交接給其他人修改

1. 以 manager 登入，從第 1 步確認清單及兩班時間。
2. 第 2 步依產線設定預設日目標，各站共用；不需先完成人員或配置。
3. 第 3 步選職務，將示範姓名改成實際人員；第 4 步到獨立頁分配各線兩班與 OWNER。
4. 第 5 步下拉選既有產線／Model，在同表新增、啟用職務／站點及選產量來源站，自動沿用預設目標與人員；不會被其他線尚未分配的人員卡住。
5. 第 6～8 步調整分組、產量來源、警示與外觀。Save settings 發布共享設定；Save draft 只保留目前瀏覽器及帳號。
6. 新設定不會自動改寫 11/3 已存的目標、人員及站點快照。目前填報的 Target／Actual／Issue 都依站點、時段獨立保存，不會同步其他站。

目前名冊及示範紀錄均標示 [SIMULATION]。正式使用前請改成現場資料；登入帳號與人員名冊是不同用途，新增人員不會建立登入帳號。

## 新版整合填報（2026/11/06）

目前整合表每站都有 Target／Actual／Issue，站點直接列出；改 Target 只重算該站當日合計，不改預設或別站。Excel 允許各站不同值，但必須可唯一識別站點。歷史示範數值保留；新 Model 在配置頁自行新增職務／站點，不再顯示舊配置推薦。停用保留配置列，刪除則移出清單並在儲存後生效；重新新增不會重用已刪除的配置 ID 或實績。

## 站點順序與批次填寫（2026/11/07）

管理員可在所選 Line／Model 的配置拖曳把手或用上下按鈕，儲存後填報、明細與匯出沿用順序，原有範例和現場資料保留。填報標題旁新增「同時段批次填寫」：選班別及時段，可一起設定各啟用站 Target／Actual，輸入欄覆蓋個別值，之後仍可逐站修改。空白保留原值，0 寫入零，異常及日目標預設不變；歷史時段不一致時請個別填寫。詳見[填報員教學](./MEMBER_GUIDE.md)。
