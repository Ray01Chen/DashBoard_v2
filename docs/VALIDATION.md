# 無產出站、跨產線批次填寫與獨立頁面驗證紀錄

驗證日期：2026-11-07。自動測試使用獨立 SQLite、Port 與 DEMO 資料；正式服務阻擋設定／報表寫入，只測試瀏覽器草稿操作與資料比對。

## 本次修正

- 產線配置最左欄依序顯示拖曳把手、序號，職務／站點下拉欄位對齊，上下移動按鈕移到操作欄。同組 Line／Model 分別排序，儲存後填報、明細及匯出依此順序。
- 新增「有產出」設定，與 Active 分開。無產出站仍顯示，沒有可填欄位，既有產量／異常可展開查閱；不刪除或重設歷史資料，重新勾選可恢復填報。既有設定未包含此欄時預設有產出。
- 無產出站不列入批次或 Excel 範本，匯入及直接 API 不接受它的生產修改；產量來源只列啟用產出站。全部無產出時可正常儲存，來源停用、看板不產生虛構數字或警示。CSV 報表仍保留已存歷史。
- 同時段批次視窗可改 Line／Model，保留尚未套用的數字並重新預覽。套用或關閉後回到所選配對及時段；沒有產出站的目的配對會顯示原因並禁止套用。上方右側醒目入口及各線標題右側入口皆可使用，產線名稱置中。
- 產品標題移除 Model 前綴，以第一個 `-` 分成主碼及括號後段兩行，無 `-` 就一行。原始名稱、ID、Excel 識別及報表快照不變。
- 新增共用頁面路由目錄；HTTP 伺服器與瀏覽器使用相同路徑。總覽、明細、填報、教學及八個設定步驟各有網址，支援直接開啟、重整、上一頁／下一頁及帳號權限。設定步驟共用草稿，取消離開時同時保留草稿及原網址。未命中路徑維持 404，資料仍由驗證過的 API 提供。
- 排序使用配置陣列既有順序，不重建站點或改 ID；其他配對與已刪歷史 ID 的位置保留。明確保留目前產量來源，避免原先依最後一站推定的來源因排序變更。
- 填報標題旁新增同時段批次填寫。先預覽各啟用站現值，Target／Actual 可一起套用或只填一欄。輸入欄會覆蓋先前個別值；空白保留原值、0 寫入零。套用後逐站編輯仍獨立，再套用可再次覆蓋。
- 批次只處理指定生產日期、Line／Model、班別及精確起迄時段。保留異常、其他時段與日目標預設；更新各站當日 Target 合計。沒有相同歷史時段或存在重複對應時拒絕，避免猜測。
- 新增原子批次端點，先驗證全部站點及設定版本再於同一交易寫入。任一版本衝突整批不寫；更新預覽保留輸入值，確認後再套用。網路結果不明時先重新預覽，不宣稱已取消寫入。
- 預覽與編輯窗保留在表格重繪範圍外；批次按套用才送出，關閉可取消未送出的數字。標題按鈕固定於橫向捲動可見範圍。已儲存與歷史報表皆以目前站點順序顯示。
- 修正異常編輯窗教學圖片未加入靜態路由白名單的問題，並加入批次填寫圖片；瀏覽器測試逐張驗證 HTTP 200。
- 填報左側只列職務／站點，移除人員、OWNER、來源標記及目標資訊；Target、Actual 並排，班別合計與全日目標移至右側。正式資料桌面列高約 112px。
- 異常只顯示一行新增按鈕或文字摘要，點開獨立編輯窗；長文字不撐高表格。支援快捷原因、多行、2,000 字元上限與清除說明。
- 完成、X、Esc、點視窗外及 Ctrl+Enter 關閉並儲存；只開啟不寫報表。F2 從數字欄開啟當格異常，關閉後回原欄位。早晚班／站點鍵值在開啟時固定，不會因後續選項而寫錯資料。
- 編輯窗保留在表格重新繪製範圍外，背景刷新不破壞文字、焦點或游標。失敗時保留摘要與草稿，右側恢復控制可重試；版本衝突仍使用原有逐站合併流程。
- 人員仍由伺服器保存，可在生產明細查看；移除不再使用的填報人員呈現函式與測試，歷史資料與明細的測試保留。Excel 工具預設收合，展開狀態不因背景刷新消失。
- 產線配置用下拉選既有 Line／Model 配對；列內不再重選 Model。職務、站點、自動人員、啟用與新增整合在同表。
- 早晚班人員依所選配對與職務帶入，OWNER 依配對帶入。未分配時顯示提示，不從其他 Model 借用人員。
- 移除舊 Model 配置推薦；只顯示所選配對自己的配置。取消 Active 暫停並保留列，Delete 從草稿移除，儲存、重整後不再出現。重新新增同站點使用新 ID，歷史報表保留。
- 刪除新建未存列、已儲存列、來源站及最後一站皆有實際操作驗證。已存在但停用的職務／站點提示直接啟用原列，不讓新增造成誤解。
- 移除配對或清單項目也移除其目前配置；重新建立同名項目不復活已刪配置。後端保留歷史 ID 並拒絕重新啟用已刪 ID；已刪站的歷史修改不插入今日的新時段。
- 產量來源移到同區，選一個啟用站點。看板目標、實績、差額、趨勢及警示以此站為準，避免製程站重複加總。切換目前配對的來源會立即用新站；已移除配對使用保存的歷史來源。
- 生產填報只篩選 Line／Model，不需選站點。所有站點各自顯示 Target、Actual、Issue，支援全天、單班及時段模式。
- 每站預設目標依配對的日目標與兩班生產分鐘分配，排除休息並維持整數總和。修改時段目標只重算該站當日合計，不改日目標預設或其他站。
- 每站獨立自動儲存、版本檢查與衝突合併；不再把一站的目標或實績同步到其他站。新站不繼承別站的實績與修改。
- Excel 支援不同站不同數值；空白保留既有值，0 為明確填值。不明確的 Line／Model／職務／站點會在預覽時阻擋，不猜測對應站。
- 沒有啟用站點時保留已配置配對與目標預覽；管理員可直接開該配對配置，填報員看到請管理員完成配置的說明。
- 三語介面、依帳號顯示的教學、管理員／填報員文件、英文指南與郵件草稿同步更新。13 張操作截圖使用獨立 DEMO 資料，包含無產出站唯讀歷史及可選產線的批次視窗。
